# Effect of Chinese ASR errors on Chinese-to-English translation

DRDO internship project. A cascaded ASR to MT evaluation: Chinese speech is recognised by two ASR systems, the transcripts are translated by TowerInstruct-7B, and the translations are scored against English references to measure how much quality is lost to recognition errors.

**Pipeline (848 sentences, pilot study with synthetic speech)**

1. `01_datasets`: build `<audio, Chinese text, English reference>` pairs from CoVoST 2 and FLEURS
2. `02_tts`: generate speech with Edge-TTS (four Mandarin voices)
3. `03_asr`: transcribe with Whisper large-v3 and Paraformer-zh; compute CER
4. `04_translate`: translate the correct text and both transcripts with TowerInstruct-7B-v0.2
5. `05_score` / `07_rescore_excl`: BLEU, chrF++, COMET-22, CER buckets, worst cases (`07` excludes one defective clip)
6. `06_audio_check`: automatic quality check of every TTS clip

## Headline results (848 clips)

| Input to TowerInstruct | BLEU | chrF++ | COMET-22 |
|---|---|---|---|
| Correct Chinese text (clean) | 27.81 | 52.46 | 0.8195 |
| Whisper large-v3 transcript (CER 6.57%) | 24.24 | 49.21 | 0.7827 |
| Paraformer-zh transcript (CER 6.27%) | 23.50 | 48.89 | 0.7899 |

Most of the loss comes from a minority of badly recognised sentences, mainly homophone errors in rare names and technical terms. Full details, tables, figures and the comparison with the reference papers are in the report.

## Reproducing

The notebooks were run on Kaggle (Python 3.13, two T4 GPUs for ASR, translation and COMET; CPU for TTS and the audio check). Each stage published its output as a private Kaggle dataset that the next stage reads, so run them in order and attach the previous stage's dataset as input. `01_datasets`, `03_asr` and `04_translate` need Internet on and a Hugging Face token stored as a Kaggle secret named `HF_TOKEN`. `05_score` installs COMET without its dependencies and patches one function (see Appendix A of the report).

To rebuild the report: `python report/build_report.py` (needs Chrome or Edge, matplotlib and PyMuPDF; the duration figure also needs the TTS audio, which is not in this repository).

## Not included

The TTS audio, intermediate datasets and the two reference papers are not in this repository. The audio can be regenerated by running `02_tts`.
